# Candy Sales Analysis Using Microsoft Excel

## Project Overview

This project was completed as part of my data analysis learning experience with TechyJaunt. It focuses on exploring candy sales data to examine sales performance and revenue generated by different products.

The project demonstrates how Microsoft Excel can be used to organise business data, analyse product performance, and present information that can support business decision-making.

## Project Objectives

- Examine sales performance across candy products.
- Analyse revenue generated by individual products.
- Identify useful patterns in product sales and revenue.
- Practise using Excel to analyse and present business data.

## Tools Used

- **Microsoft Excel** — spreadsheet analysis, calculations, and data presentation.

## Analysis Focus

The project focuses on two key business questions:

1. How do sales figures vary across the candy products in the dataset?
2. Which products generate the most revenue?

The answers to these questions should be supported by the results and calculations in the accompanying workbook.

## Skills Demonstrated

- Business data analysis
- Sales and revenue analysis
- Microsoft Excel
- Product performance analysis
- Data interpretation

## Project File

- `Candy Project.xlsx` — the Excel workbook associated with this project.

## Learning Outcome

This project provided practical experience in examining sales data and exploring how product-level performance can be assessed using Microsoft Excel.
